# Projeto de Capacitação EJCOMP

Projeto desenvolvido durante a capacitação de trainees da **Empresa Júnior de Computação (EJCOMP)**. O objetivo foi aplicar conceitos práticos de desenvolvimento web front-end e arquitetura de software.

## Estrutura do Projeto

```text
├── assets/        # Arquivos de imagem e mídia usados no projeto
├── build/         # Scripts principais em JavaScript transpilado (output)
├── componentes/   # Componentes reutilizáveis (Footer e Header do site)
└── scripts/       # Código-fonte principal desenvolvido em TypeScript
```
